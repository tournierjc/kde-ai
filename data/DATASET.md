## Mix (train)

tools 6000, kde 6000, cachyos 4500, bug_search 6000, solve 4500, rag 1500, refuse 1500.

KDE/CachyOS/tools/rag slices include Linux, Plasma/KWin, CachyOS, sysadmin, and network-admin trajectories from `data/generators/expert.py` (allowlisted tools + manpage cites). User turns are paraphrased as how / where / I-want / best-way / example questions (`data/generators/questions.py`); RAG is natural how-tos, not `Quote title from local docs (n)`.

Eval uses the same proportions at 500 rows.

## How to regenerate

```bash
PYTHONPATH=src:. python -m data.generators.build_full
PYTHONPATH=src:. python -m data.validators.validate_jsonl --gold data/gold --full data/out
```

Teacher (optional, Spark): `Qwen/Qwen2.5-32B-Instruct` filling `data/templates/`. Gold files are never overwritten by the teacher. The committed generator expands gold templates so a laptop can produce the 30k artifact without the teacher.

## Split

Gold eval ids: `data/gold/eval_ids.txt` (excluded from any gold→train merge). Full train/eval ids are disjoint prefixes (`train-*` / `eval-*`).
